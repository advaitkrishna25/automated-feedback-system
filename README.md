# Automated Feedback Calling System

## Project Overview

The Automated Feedback Calling System is a web-based platform designed to automate customer feedback collection through voice calls.

The system collects customer responses, converts speech into text, processes feedback data, and displays the results on a dashboard website.

---

# Technologies Used

| Technology | Purpose |
|---|---|
| TypeScript | Backend and frontend development |
| Node.js | Backend runtime |
| React | Frontend dashboard |
| Whisper | Speech-to-text conversion |
| MongoDB | Database |
| Twilio | Automated calling |
| FFmpeg | Audio processing |
| PyTorch | Machine learning framework |
| Git & GitHub | Version control |
